# RiskScope Analytics - Startup Investment Platform

Intelligent investment analysis platform for startups using GRU-based risk prediction and ROIC optimization.

## Features

- **Smart Investment Analysis**: Filter companies by sector, investment amount, and risk tolerance
- **GRU Risk Prediction**: Machine learning model for startup risk assessment
- **ROIC-based Ranking**: Companies ranked by Return on Invested Capital
- **Interactive Visualizations**: Charts for ROIC vs Risk and revenue distribution
- **Portfolio Optimization**: Intelligent investment recommendations
